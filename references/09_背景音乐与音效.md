# 09 · 背景音乐与音效

> 声音的第一原则：观众要听见"人在说话"，其次才是"有氛围"。

## 1. 优先级

```
原始人声（100%） > 重点音效（20–40%） > 背景音乐（10–20%）
```

任何情况下 BGM 盖过人声 = 不合格。

## 2. 音效触发表

| 触发内容 | 音效 | 音量 | 时长 |
|---|---|---|---|
| 封面标题 | 轻量 Impact / soft hit | -18dB | 0.4–0.6s |
| 核心关键词出现 | Click / Pop | -20dB | 0.1–0.2s |
| 流程节点连接 | Whoosh | -18dB | 0.3–0.5s |
| 数据变化 | Tick / tick-tick | -22dB | 0.1s × N |
| 关键结论 | 柔和强调音（低音埢） | -20dB | 0.6–1.0s |
| 章节切换 | 简洁过渡音 | -18dB | 0.4s |
| 对比出现 | 双音（左/右） | -20dB | 0.2s × 2 |
| 错误示范 | 下行短音 | -20dB | 0.3s |

## 3. 密度控制

- 默认每 10 秒 1–3 个重点音效。
- 连续音效之间至少间隔 0.8s，不许连击。
- 同一类音效在 30 秒内不超过 4 次。
- 纯阅读停留段（`a5`）不配音效。

## 4. BGM 使用

| 项目 | 要求 |
|---|---|
| 音量 | -24 ~ -18 dB（相对人声） |
| 选曲 | 无人声、无强节拍、可循环 |
| 风格 | 科技 → 极简电子/氛围；成长 → 轻钢琴/自然声；商业 → 低频稳定 |
| 避让 | 人声起时 ducking 至 -30dB，人声停 0.3s 后回位 |
| 段落 | 可在章节切换处淡入淡出（0.5s） |
| 结尾 | 收尾 2s 内淡出至 0 |

**禁用**：综艺罐头笑声、抖音爆款 BGM、有明显旋律记忆点的流行曲、来源不明的网络音乐。

## 5. 混音链路

```
人声链：降噪 → EQ → loudnorm(-16 LUFS)
BGM 链：音量归一 → 低切 120Hz → ducking(sidechain by voice)
音效链：单条 -20dB 左右 → 硬切
↓
最终混音 → 限制器 -1dB → 输出 48kHz 立体声
```

FFmpeg 侧链压缩示例：

```bash
ffmpeg -i voice.wav -i bgm.wav -filter_complex \
"[0:a]volume=1.0[v];[1:a]volume=0.35,highpass=120[b];\
[b][v]sidechaincompress=threshold=0.02:ratio=6:attack=15:release=300[m];\
[v][m]amix=inputs=2:weights=1 0.5:duration=longest[a]" \
-map "[a]" mix.wav
```

## 6. 素材授权

- 音乐/音效必须来自可商用库（自有授权、CC0、已购买）。
- 在 `assets/music/CREDITS.md` 登记：文件名、来源、授权类型、获取日期。
- 来源不明 → 不用。宁可静音，不可侵权。

## 7. 验收

- [ ] 人声清晰，无破音、无削波、无底噪
- [ ] 响度 -16 ± 1 LUFS
- [ ] BGM 全程未盖过人声（抽 5 个点听测）
- [ ] 音效数量与内容匹配（宁少不多）
- [ ] 无重复爆音、无廉价综艺音
- [ ] 所有素材授权可追溯
