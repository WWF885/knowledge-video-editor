# 06 · 智能分镜与逐秒动态

> 三分钟视频 = 180 个格子。每个格子都要有内容，但不是每个格子都要有变化。

## 1. 四层时间精度

| 精度 | 单位 | 必须回答 |
|---|---|---|
| 章节层 | 10–30s | 这一段讲什么？换成哪个章节？ |
| 构图层 | ≈3s | 画面该不该变？真人占比够吗？ |
| 动态层 | ≈1s | 这一秒观众看到什么在动？ |
| 动画层 | 0.2–0.5s | 元素的进出、强调曲线 |

## 2. 构图变化评估（每 3 秒一次）

每次评估问四个问题：

1. **当前是什么构图？**（全屏真人 / 全屏知识 / 画中画 / 左右分屏 / 上下分屏 / 实景）
2. **上一镜头是什么？** 是否已经连续 6 秒没变？（超过就要换）
3. **内容需不需要图解？** 出现"三个原因""两个步骤""对比"就必须上图。
4. **观众会不会疲劳？** 连续 3 个镜头同一构图 = 疲劳。

**不要机械 3 秒一切。** 复杂知识需要 6–9 秒给观众读；简单过渡 1.5–2 秒即可。

## 3. 视觉多样性配额（3 分钟参考）

| 项目 | 建议 |
|---|---|
| 视觉表现形式 | 6–10 种 |
| 真人全屏累计 | 30–50%（按类型浮动） |
| 图解类镜头 | ≥ 8 个 |
| 单一构图连续 | ≤ 9 秒 |
| 无变化镜头连续 | ≤ 4 秒 |

配额是健康度参考，不是考核指标。**内容需要的就多用，不需要的别硬塞。**

## 4. 每秒都要有安排

每一秒必须落到下面某一类：

| 安排类型 | 说明 |
|---|---|
`a1` 内容推进 | 新节点出现、新卡片进场 |
`a2` 信息强调 | 关键词高亮、局部放大、颜色脉冲 |
`a3` 数据演化 | 数字滚动、柱形增长、曲线绘制 |
`a4` 空间运动 | 推镜、平移、景深变化 |
`a5` 阅读停留 | 画面静止，给观众读（**这是合法安排**） |
`a6` 人物表达 | 真人出镜、表情/手势 |

`a5` 不是"没安排"，是"刻意的留白"。一条 3 分钟视频里 `a5` 占比 15–25% 是健康的。

## 5. 节奏曲线

不要全程一个速度。切法：

```
开场（0–15s）   : 快，2–3 秒一切，抓注意
铺陈（15–60s）  : 中，4–6 秒，进结构
主体（60–150s） : 中慢，5–9 秒，讲透
收束（150–180s）: 快，2–4 秒，回顾 + 行动号召
```

## 7. 动画曲线速查

| 曲线 | 适用 |
|---|---|
| `easeOutCubic` | 进场、元素出现（快进慢停） |
| `easeInOutQuad` | 位移、生长（两头缓） |
| `spring(smooth)` | 卡片、标签落位（轻微回弹） |
| `linear` | 进度条、数字滚动 |
| `easeInQuad` | 出场（慢起快走） |

不要用 `bounce` 做主进场，只在"落定"时用极轻回弹。

## 8. 转场选择

| 场景 | 转场 |
|---|---|
| 同构图、同人物 | 硬切 |
| 同类型、换内容 | 0.2s 交叉淡化 |
| 换章节 | 背景层切换 + 元素重排（0.4s） |
| 真人 ↔ 知识 | 知识卡片从画面一侧推入覆盖 |
| 时间跳跃 | 时间轴滑动或纹理擦除 |

禁止：3D 翻转、百叶窗、随机马赛克、镜头光晕。

## 9. 分镜自检

- [ ] 每个 scene 的 start/end 连续无重叠、无空洞
- [ ] 每个 scene 都有 `visual_type` 与至少一条 `animation_plan`
- [ ] 单一构图连续 ≤ 9s
- [ ] 每 3 秒有一次构图/信息评估记录
- [ ] `a5` 阅读停留占比 15–25%
- [ ] 章节切换点有明确转场
- [ ] 与字幕 `subtitle_ref` 对齐


## 真人覆盖（每镜必查）

排完分镜后逐镜检查：这一镜有没有人？

| 镜头类型 | 真人形态 | 检查点 |
|---|---|---|
| `presenter` / `presenter_pip` | 全屏或画中画 | 人脸不糊、不裁头 |
| 所有知识类镜头 | **右上角 V21 圆形头像** | 头发+全脸+上肩齐全，且不压标题/卡片/字幕 |
| `cover` | 右上角小头像（176/216px） | 不抢封面标题 |

只要出现"整段没有任何真人"的镜头，就判定不合格，必须补头像或改成真人镜头。
