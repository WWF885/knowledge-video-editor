# 02 · 自动精细剪辑

> 精剪的目标不是"变短"，是"没有废话，且一句没丢"。

## 1. 六类处理对象

| 类型 | 判定依据 | 处理 | 风险 |
|---|---|---|---|
| 重复表达 | 相邻两句语义相似度 > 0.85 | 保留最完整、语气最好的一次 | 误删递进关系（"不只是 A，更是 B"） |
| 口误 | 说话人自我修正（"不对，我是说…"）、明显错字 | 删错留对 | 删掉后语义跳跃 |
| 无效停顿 | 静音 > 0.8s 且前后非转折 | 压到 0.25–0.35s | 压太狠显得赶 |
| 语气词 | 嗯/啊/呃/那个/就是说（无实义） | 高频时选择性删 | 删多了失去人味 |
| 开场准备 | 前 0–3s 调整、咳嘿、找状态 | 裁掉 | 开场金句被误删 |
| 结尾拖尾 | 结束语后的空白、重复告别 | 裁掉 | — |

## 2. 必须保留的东西

- **观点句**：任何"我认为/本质上/关键是"的句子，一字不动。
- **论据**：数据、案例、引用的完整性优先于时长。
- **情绪高点**：语气加重、停顿后的重音，这些是观众的注意力锚点。
- **转折连词**：但、然而、所以、因此 —— 删了逻辑就断。

## 3. 不能删的四条红线

1. ❌ 不允许为压时长删掉一个完整论据。
2. ❌ 不允许改写原话（除了删，不做词序调整）。
3. ❌ 不允许把两句话"缝合"成一个不存在的句子。
4. ❌ 不允许删除否定词（"不""没有""别"）—— 一删意思就反了。

## 4. 音频处理链（顺序不可颠倒）

```
trim → 高通 80Hz（去低频噪声）→ afftdn 降噪 → 3-band EQ 提亮人声
→ loudnorm 响度归一（目标 -16 LUFS，双通道）→ 限幅 -1dB
```

参数建议：

| 环节 | 参数 |
|---|---|
| 高通 | `highpass=f=80` |
| 降噪 | `afftdn=nf=-25:nr=12` |
| EQ | `equalizer=f=120:t=q:w=1:g=-2`、`equalizer=f=2500:t=q:w=1:g=+1.5` |
| 响度 | `loudnorm=I=-16:TP=-1.5:LRA=11` |
| 采样 | 48kHz / 立体声（源为单声道时复制为双声道，保持相位一致） |

## 5. 时间轴重映射（最容易出错的地方）

删掉片段后，字幕/分镜/动画全部要跟着改。做法：

```json
{
  "cuts": [{"start": 0.0, "end": 2.4, "keep": false}, {"start": 2.4, "end": 18.0, "keep": true}],
  "mapping": [[2.4, 18.0, 0.0], [18.0, 45.2, 15.6]]
}
```

`mapping` 每行 `[原起点, 原终点, 新起点]`。字幕时间、动画时间、封面时长全部通过这个映射换算。**任何时间改动都必须走 mapping，不许心算。**

## 6. 跳切怎么不突兵

删掉停顿会造成画面跳动。三种处理，按成本排序：

1. **知识画面覆盖**（最推荐）：切到流程图/卡片，2–4 秒，再回到真人。
2. **轻微推镜**：`scale=1.03` + 缓慢平移，掩盖位置突变。
3. **交叉溶解**：0.2–0.3s，只在同一构图内使用。

不要用花哨转场掩盖跳切 —— 那会让观众更注意到"这里被剪过"。

## 7. 精剪验收

- [ ] 口播文稿与成片逐句可对齐（无凭空出现/消失的句子）
- [ ] 静音段总时长 ≤ 全片 8%
- [ ] 语气词密度 ≤ 每 10 秒 1 个
- [ ] 响度 -16 ± 1 LUFS，无削波
- [ ] 首尾干净，无准备动作与拖尾
- [ ] 关键论据完整率 100%
