# 04 · 横竖屏与动态导航

> 同一份内容，两种构图。不是缩放，是重排。

## 1. 基础参数

| 项目 | 横屏 | 竖屏 |
|---|---|---|
| 比例 | 16:9 | 9:16 |
| 分辨率 | 1920×1080 | 1080×1920 |
| 帧率 | 跟原片（默认 30 / 25） | 同左 |
| 动态导航栏 | **必须配置** | 按需（默认开，短于 60s 可关） |
| 图解布局 | 左右展开 | 上下展开 |
| 真人画中画 | 左/右侧竖条 | 上/下安全区横条 |
| 字幕 | 底部双语 | 中下部安全区双语 |
| 知识展示 | 大空间、完整逻辑 | 核心信息、逐步展开 |

## 2. 默认行为

- **自动识别原片方向**并按原方向出片。竖屏原片不强行转横屏。
- 用户要求双出时：**共用**内容分析、精剪时间轴、字幕数据；**分别**布局、分别渲染。
- **禁止**把横屏成片裁剪成竖屏。裁出来的竖屏，人物被切头、图表被切边，一眼假。

## 3. 安全区（关键，决定成片能不能发）

### 竖屏 1080×1920

| 区域 | 数值 | 用途 |
|---|---|---|
| 顶部平台 UI 遮挡 | 0–220px | 不放任何信息 |
| 底部平台 UI 遮挡 | 1700–1920px | 不放字幕 |
| 字幕基线区 | 1450–1680px | 双语字幕 |
| 视觉主体区 | 260–1420px | 知识画面 + 人物 |
| 左右边距 | 各 64px | — |

### 横屏 1920×1080

| 区域 | 数值 | 用途 |
|---|---|---|
| 导航栏 | 0–86px（约 8%） | 章节导航 |
| 视觉主体区 | 96–940px | 知识画面 + 人物 |
| 字幕区 | 940–1030px | 双语字幕 |
| 左右边距 | 各 96px | — |

> 数值随平台改版会变，`config/safe-areas.json` 是唯一真源，脚本从这里读。

## 4. 横屏动态章节导航栏

### 4.1 结构

```
┌───────────────────────────────────────────────┐
│  现状  │  逻辑  │  案例  │  总结             │
│ ████████████████░░░░░░░░░░░░░░░░░  进度 ▓▓▓▓ │
└───────────────────────────────────────────────┘
```

### 4.2 规范

| 项目 | 要求 |
|---|---|
| 章节数 | 3–6 个 |
| 章节名 | 2–6 字，动宾或名词短语 |
| 高度 | ≤ 画面 8%（1080p ≤ 86px） |
| 位置 | 顶部，距顶 24–32px |
| 当前章节 | 高亮色 + 字号放大 8% + 下划进度条 |
| 已完成章节 | 弱化（透明度 0.45），可加 ✓ 小标记 |
| 未开始章节 | 低调（透明度 0.25） |
| 切换时机 | 与原语音时间戳对齐（章节首句起始） |
| 过渡 | 300–500ms ease-out，进度条平滑推进 |
| 封面期间 | **隐藏**，正文第一镜头起出现 |
| 结尾 | 最后一章完成后保留至片尾前 2s |

### 4.3 按类型换导航语义

| 类型 | 导航形态 |
|---|---|
| 故事 | 事件阶段（起因 → 转折 → 结果） |
| 实操 | 操作步骤（01 → 02 → 03） |
| 分析 | 逻辑环节（现状 → 原因 → 预测） |
| 知识 | 知识层级（是什么 → 为什么 → 怎么用） |
| 观点 | 论点推进（误区 → 真相 → 做法） |

### 4.4 常见错误

- ❌ 导航栏做成一整条色块，占高 15% —— 抢内容空间
- ❌ 章节名太长（"我们来看看第一个关键问题"）
- ❌ 一次性全部高亮（等于没导航）
- ❌ 封面阶段就出现（破坏封面完整性）
- ❌ 进度条跳变（应连续推进）

## 5. 竖屏布局要点

1. **上下分区**：上 1/3 放标题/结论，中 1/3 放图解，下 1/3 放真人 + 字幕。
2. **逐步展开**：竖屏空间窄，一次只讲一个点，靠时间换空间。
3. **真人画中画**：常见形态是顶部圆形/圆角矩形，或底部半身条。
4. **字幕更小**：竖屏中文字号 44–56px，英文 28–34px（1080 宽基准）。
5. **避免满屏文字**：竖屏满屏文字 = 观众放弃阅读。

## 6. 双出的工程约定

```
project/
├── horizontal/   storyboard.json / output.mp4 / cover.png
└── vertical/     storyboard.json / output.mp4 / cover.png
```

两个 storyboard 共享：`video_type`、`theme`、`chapters`、字幕文本与时间戳。
不同：`aspect_ratio`、`resolution`、每个 scene 的布局坐标、视觉组件形态、封面标题位置。

## 7. 验收

- [ ] 比例、分辨率与目标平台一致
- [ ] 所有文字、图形都在安全区内
- [ ] 横屏导航栏存在且高度 ≤ 8%
- [ ] 导航章节切换与语音对齐（误差 ≤ 0.3s）
- [ ] 竖屏未被裁切（人物头部、图表边缘完整）
- [ ] 封面期间无导航栏


## 8. 真人头像安全区（与导航条共存）

| 区域 | 横屏 1920×1080 | 竖屏 1080×1920 |
|---|---|---|
| 导航条 | y 40–124 | y 230–300 |
| V21 头像 | 右上 `x 1920-292 ~ 1920-52`，`y 152 ~ 392` | 右上 `x 1080-240 ~ 1080-48`，`y 312 ~ 504` |
| 知识内容区 | `paddingRight = padX + 344` | `paddingTop ≥ 528` |
| 字幕 | 底部安全区 | y 1450 起 |

> 布局顺序：先给导航条和头像划区，再在其中放知识内容；宁可让卡片变窄，也不要让头像压字。
