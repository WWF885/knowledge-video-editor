# 05 · 配色与视觉设计

> 高级感来自留白、字体、层级、构图，不是特效数量。

## 1. A 款 · 深空黑金（dark_gold）

适用：科技、商业、AI、管理、效率、投资。

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景基色 | `#101820` | 主背景 |
| 次级背景 | `#26323E` | 卡片、分区 |
| 强调金 | `#D5B477` | 关键词、数据、线条重点 |
| 主文字 | `#F6F3EC` | 标题、正文 |
| 次文字 | `#9AA9B6` | 说明、注释 |

衍生规则：
- 金色只用于**一个**视觉重点，全屏不超过 2 处，否则贬值。
- 卡片底 = `#26323E` + 8% 白描边 + 柔和阴影。
- 禁止纯黑 `#000000`、禁止纯白 `#FFFFFF`。

## 2. B 款 · 珍珠墨绿（pearl_green）

适用：成长、认知、文旅、教育、生活方式。

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景基色 | `#F5F2EB` | 主背景（暖白，非纯白） |
| 主深色 | `#173C39` | 标题、主图形 |
| 强调铜 | `#A17E45` | 关键词、数据 |
| 次级色 | `#E4E8E5` | 卡片、分区 |
| 辅助文字 | `#62736E` | 说明、注释 |

衍生规则：
- 暖白底必须带一点点米黄，纯白会显得廉价。
- 墨绿承担"结构"，铜色承担"焦点"，不要反过来。
- 阴影用墨绿的 8–12% 透明度，不要用灰黑阴影。

## 3. 主题选择决策

```
是否涉及 科技/商业/AI/管理/投资/效率 → dark_gold
是否涉及 成长/认知/教育/文旅/生活/情感 → pearl_green
都不像 → 看画面亮度：暗背景 → dark_gold；亮背景 → pearl_green
```

一条视频**只用一个主色体系**。允许在体系内改明暗、改背景深度、改局部强调，但不许中途换成另一套。

## 4. 排版层级（图为先，字为辅）

| 层级 | 字号（1080 基准） | 用途 |
|---|---|---|
| 主标题 | 96–140px | 封面、章节封面 |
| 章节标题 | 64–80px | 章节内首屏 |
| 要点标题 | 44–56px | 卡片标题 |
| 正文/说明 | 28–36px | 解释文字 |
| 注释/来源 | 20–24px | 出处、单位 |
| 字幕（中） | 48–60px | 双语字幕 |
| 字幕（英） | 30–38px | 双语字幕 |

**一张画面最多 3 个字号层级。** 超过就是乱。

## 5. 留白规则

- 四周安全边距 ≥ 画面短边 5%。
- 图形与文字之间 ≥ 24px。
- 一屏信息元素 ≤ 5 个（含标题）。
- 宁可多留一屏，不要挤满一屏。

## 6. 动效原则

| 类型 | 参数 |
|---|---|
| 进场 | 180–320ms，ease-out，位移 ≤ 24px，透明度 0 → 1 |
| 强调 | 240ms，scale 1.0 → 1.06 → 1.0，或颜色脉冲 |
| 转场 | 200–400ms，优先"内容切换"而非"样式炫娃" |
| 数据增长 | 600–900ms 数字滚动，配合 `tick` 音效 |
| 连线绘制 | 400–700ms 逐段绘制 |

禁止：弹跳（bounce）滥用、旋转 360°、无意义光效、粒子爆炸。

## 7. 素材规范

- 图片必须高清（≥ 1920px 宽），低清图宁可不用。
- 图标统一线性或统一面性，不许混用。
- 实景素材要有景深或运动，静止截图要加轻推镜。
- 所有素材必须有授权来源，见 `assets/README.md`。

## 8. 反例清单

| 反例 | 为什么错 |
|---|---|
| 全片 6 种颜色 | 没有主色，视觉廉价 |
| 满屏花字 | 抢注意力，信息密度过高 |
| 每个字都加阴影描边 | 糊，且印刷感像 2010 年 PPT |
| 表情包做知识配图 | 破坏权威感 |
| 渐变滥用（彩虹渐层） | 廉价 |
| 大量 3D 旋转 | 与知识内容无关 |
