# 08 · 中英字幕与安全区

> 字幕不是"加个字"，是"让听不懂的人也能看懂"。

## 1. 排布规则

```
中文在上，英文在下。
```

| 项目 | 标准 |
|---|---|
| 中文行数 | 原则上 1 行 |
| 英文行数 | 原则上 1 行 |
| 中文断句 | 按语义短句（≤ 18 字/行） |
| 英文断句 | 按从句边界（≤ 60 字符/行） |
| 展示方式 | 逐句出现、逐句消失，不做整段长显 |
| 关键词 | 自动识别并高亮（主题强调色） |
| 同步 | 与真实语音时间戳对齐（误差 ≤ 0.15s） |

## 2. 字号（1080 短边基准）

| 比例 | 中文 | 英文 |
|---|---|---|
| 竖屏 1080×1920 | 44–56px | 28–34px |
| 横屏 1920×1080 | 48–60px | 30–38px |
| 4K 出片 | 按比例放大 2× | 同 |

行距：中文行高 1.25×字号；中英之间间距 12–16px。

## 3. 位置

| 比例 | 中文基线 | 英文基线 | 说明 |
|---|---|---|---|
| 竖屏 | y = 1520（垂直居中） | y = 1576 | 距底 200px 以上，避开平台 UI |
| 横屏 | y = 968 | y = 1014 | 避开底部控制条 |

安全区数值以 `config/safe-areas.json` 为准，脚本从中读取，不写死。

## 4. 宽度实测（必须做，不许估）

不要用"字数 × 字号"来估宽度，因为中英混排、标点、数字宽度差异极大。正确做法：

```python
# scripts 内使用 fonttools 读取字体 metrics
adv = sum(font.getAdvance(c) for c in text) / unitsPerEm * font_size
if adv > max_width:  → 触发断句或降字号
```

规则：

1. 先**自然断句**（在语义边界切）。
2. 再**优化翻译**（缩短英文表达）。
3. 最后才**微调字号**（降幅 ≤ 10%）。
4. 禁止无限缩小字号；单行降到 40px 仍溢出 → 必须断句。

## 5. 翻译原则

| 原则 | 说明 |
|---|---|
| 意译优先 | 保留信息，不保留句式 |
| 术语统一 | 走 `config/glossary.json`（如 AI/大模型/知识库固定译法） |
| 口语化 | 不用书面腔；"你"而非"您"；缩略语按英文习惯（it's / don't） |
| 长度可控 | 英文通常比中文长 30–50%，翻译时就控制在 60 字符内 |
| 数字保留 | 数字用阿拉伯数字，单位用英文（3 steps / 30%） |
| 不臆造 | 中文没有的，不许加；听不懂的，宁可标 `[inaudible]` |

示例：

| 中文 | 好 | 差 |
|---|---|---|
| 真正改变的是工作方式 | What really changes is how we work. | What is really changed is the working way. |
| 别再堆工具了 | Stop stacking tools. | Please do not pile up tools anymore. |
| 三步搞定 | Three steps, done. | It can be solved by three steps. |

## 6. 高亮规则

- 每句最多高亮 1 个词组（2–6 字）。
- 高亮用强调色，不加粗（粗体会导致宽度变化）。
- 数字、结论词优先高亮。

## 7. 字幕文件格式

同时输出两种：

**SRT**（通用）
```
1
00:00:02,400 --> 00:00:05,800
真正改变的是工作方式
What really changes is how we work.
```

**subtitle.json**（渲染用）
```json
{
  "id": "sub_0001",
  "start": 2.4,
  "end": 5.8,
  "zh": "真正改变的是工作方式",
  "en": "What really changes is how we work.",
  "emphasis": "工作方式",
  "speaker": "host"
}
```

## 8. 时间戳对齐

1. 转写引擎给词级时间戳（word-level）。
2. 按语义边界合并成句，句首取首词起点、句尾取末词终点 + 0.15s 余量。
3. 精剪后必须用 `timemap.json` 重新映射时间，不许沿用原片时间。

## 9. 验收

- [ ] 中英逐句对应，无错行、无漏译
- [ ] 每句都在安全区，未遮挡核心知识
- [ ] 宽度实测通过（无溢出）
- [ ] 与语音对齐误差 ≤ 0.15s
- [ ] 高亮数量合规（每句 ≤ 1）
- [ ] 术语与 glossary 一致
- [ ] 竖屏/横屏分别渲染，未共用一套坐标
