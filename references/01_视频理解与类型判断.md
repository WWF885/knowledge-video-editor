# 01 · 视频理解与类型判断

> 判断错类型，后面全错。这一步是整个流水线里最贵的判断。

## 1. 先看整体，再看段落

两遍法：

**第一遍（整片）**：只看结构，不看细节。回答三问：
- 他在讲什么？（主题一句话）
- 他在教、在说、在证，还是在讲事？（动作类型）
- 听完观众会得到什么？（价值交付物）

**第二遍（段落）**：按 10–30 秒切块，给每块打属性标签。

## 2. 六种类型判定表

| 类型 | 典型信号 | 判断关键词 | 策略倾向 |
|---|---|---|---|
| `knowledge` 知识科普 | 有定义、有原理、有步骤、有"为什么" | "什么是""原理是""分为三步" | 结构图 / 流程 / 白板，真人降到 20–35% |
| `practice` 工具实操 | 出现软件界面、鼠标、按钮 | "点击""打开""设置成" | 录屏 + 局部放大 + 光标引导，真人 15–30% |
| `analysis` 商业分析 | 数字、增长、对比、因果 | "增长 30%""因为…所以""对比来看" | 数据图 / 对比图 / 因果链，真人 25–40% |
| `opinion` 观点表达 | 判断句、立场、反驳 | "我认为""真正的...是""别再" | 真人为主 + 关键词 + 案例，真人 40–60% |
| `story` 故事分享 | 时间顺序、人物、转折 | "那年""后来""结果" | 真人叙事 + 场景 + 时间轴，真人 45–65% |
| `industry` 行业解读 | 政策、格局、地域、参与者 | "政策""赛道""上游下游" | 地图 / 引用 / 实景 / 图表，真人 25–45% |

判定优先级：**证据数量 > 语气感觉**。至少命中 2 个关键词信号才定类型，否则判 `opinion`（这是最宽容的兜底）。

## 3. 混合内容怎么处理

一条视频里混属性是常态，不是异常。规则：

1. **主类型定全局主题与配色**（占比最高的类型）。
2. **段落类型定该段视觉**（允许一段用 story 策略、下一段用 analysis 策略）。
3. **段落切换点必须做视觉过渡**（换构图或换背景层级），让观众感知到"进新章节了"。

示例：一条"我如何用 AI 做副业"的视频
- 0:00–0:40 个人经历 → `story`：真人 + 场景 + 时间轴
- 0:40–2:00 收入数据 → `analysis`：柱形 + 对比 + 数字滚动
- 2:00–3:00 操作演示 → `practice`：录屏 + 放大
- 3:00–3:30 结论建议 → `opinion`：真人 + 大字结论

## 5. 常见误判

| 误判 | 后果 | 纠正 |
|---|---|---|
| 把"讲故事型知识"判成 knowledge | 全片流程图，情绪被杀 | 看是否有第一人称时间线 |
| 把"带数据的观点"判成 analysis | 满屏图表，观点不清 | 看结论句是不是立场句 |
| 把"录屏 + 解说"判成 knowledge | 丢掉关键操作细节 | 画面里有没有 UI |
| 只判整片不判段落 | 中段风格断裂 | 必须做段落级标注 |

## 6. 判断不出来怎么办

- 拿不准 `knowledge` 还是 `opinion` → 选 `opinion`（真人占比高，容错高）。
- 拿不准 `practice` 还是 `knowledge` → 看画面：有 UI 就 `practice`。
- 实在读不懂内容 → 停下来报告，不要猜。剪错方向的成本远高于多问一句。
