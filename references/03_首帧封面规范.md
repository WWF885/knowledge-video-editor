# 03 · 首帧封面规范

> 第一帧就是封面。它决定点击率，也决定"这条视频是不是专业的"。

## 1. 硬指标（违反即返工）

| 项目 | 标准 |
|---|---|
| 标题行数 | ≤ 2 行 |
| 每行字数 | ≤ 4 字（英文单词、数字同样计数） |
| 总字数 | ≤ 8 字 |
| 位置 | 画面视觉中心（非正中央时，水平居中、垂直 45–55%） |
| 字体 | 特粗黑体（思源黑体 Heavy / 阿里巴巴普惠体 Bold 起） |
| 字号 | 横屏主行 110–150px（1080p 基准）；竖屏主行 90–120px |
| 第二行处理 | 字号为主行的 60–70%，或同字号换强调色 |
| 关键词 | 用强调色（金 #D5B477 / 墨绿强调 #A17E45） |
| 第一帧状态 | 标题**完整、清晰、静态可读**，不允许半透明或动画中 |
| 停留 | 1.5–2 秒（默认 2 秒） |
| 第二镜头 | 标题**完全消失**，不能残留在角落 |
| 封面图 | 额外导出与第一帧 100% 一致的 PNG |

## 2. 为什么卡"每行 4 字"

手机端信息流里，封面缩略图只有 180px 宽左右。4 个汉字在这个尺寸下还能辨认，5 个就开始糊。**这是可读性下限，不是审美偏好。**

例外：英文单词允许略超（如 "AI" "GPT"），但整行视觉宽度不得超过 4 个汉字宽度。

## 3. 标题提炼方法

四步：

1. **抓冲突**：找出"旧的认知 vs 新的认知"。例："努力 ≠ 有效"
2. **抓结果**：观众能拿到什么。例："3 步做完"
3. **抓对象**：让目标人群 1 秒认出"这是说我的"。例："职场人必看"
4. **压缩到 8 字内**：删虚词、删修饰、留动词和名词。

标题公式（按有效性排序）：

| 公式 | 示例 |
|---|---|
| 结论前置 | "别再学工具了" |
| 数字具体 | "3 步搞定选题" |
| 反差对立 | "越努力越穷" |
| 身份锁定 | "给 30 岁的你" |
| 悬念缺口 | "他被裁后做了啥" |

## 4. 竖屏 vs 横屏封面差异

| | 横屏 16:9 | 竖屏 9:16 |
|---|---|---|
| 标题区 | 画面中央偏左或居中 | 画面上 1/3，避开顶部平台 UI 安全区 |
| 副标题 | 可放标题下方，小字号 | 通常不放，或压到极小 |
| 背景 | 可留更多环境信息 | 背景需更简洁、层次更强 |
| 人物 | 可同框，占 1/3 一侧 | 人物常放下半区，标题独占上半区 |

## 5. 背景处理三选一

1. **纯色 + 微噪点**：深空黑金用 `#101820`，珍珠墨绿用 `#F5F2EB`。最稳，最不容易翻车。
2. **模糊人像**：真人画面高斯模糊 radius 40–60，压暗 30%，标题叠在上层。有温度。
3. **抽象图形**：几何线条 / 网格 / 光斑，透明度 ≤ 15%。适合科技题材。

禁止：花哨素材拼贴、纯白底黑字、竖排文字（除非古风题材）。

## 6. 动画时序（封面段 0–2s）

| 时间 | 动作 |
|---|---|
| 0.0s（第一帧） | 标题已完整呈现，静态可读 |
| 0.0–1.4s | 极轻推镜 `scale 1.00 → 1.04`，标题位置不动 |
| 0.6s 起 | 关键词渐亮（透明度 0.7 → 1.0），不许位移 |
| 1.6–2.0s | 整体淡出，衔接第二镜头 |

**关键：动画是"呼吸"，不是"入场"。** 观众第一眼看到的必须已经是成品，不是正在生成的东西。

## 7. 自检（渲染前必跑）

```bash
python3 scripts/render_video.py --cover-only --storyboard work/storyboard.json --out cover_check.png
```

逐项看：
- [ ] 第一帧标题是否完整
- [ ] 是否超过 2 行 / 每行是否超 4 字
- [ ] 缩略到 180px 宽还能不能读
- [ ] 第二镜头处标题是否彻底消失
- [ ] 导出 PNG 与第一帧是否像素级一致
