# 10 · 质检与自动修复

> 机器查"对不对"，人（或视觉模型）查"好不好"。两者都不能省。

## 1. 百分制评分

| 维度 | 满分 | 检查方式 |
|---|---|---|
| 内容准确与逻辑表达 | 25 | 视觉模型 + 文稿比对 |
| 知识可视化质量 | 25 | 视觉模型 + 组件规范校验 |
| 画面高级感与多样性 | 20 | 视觉模型（配色/留白/层级/构图切换） |
| 动态节奏与声音 | 15 | 程序（变化密度/响度/音效数）+ 人听 |
| 中英双语字幕 | 10 | 程序（宽度/同步/覆盖率）+ 视觉 |
| 横竖屏及技术质量 | 5 | 程序（ffprobe 解码/参数） |

**合格线 90 分。** 低于 90 必须定位扣分项并修复；修不好如实报告。

## 2. 15 项硬指标（任何一项不合格必须修）

| # | 检查项 | 判定方式 |
|---|---|---|
| 1 | 视频类型识别正确 | 类型与内容匹配（人工/模型复核） |
| 2 | 比例与构图正确 | ffprobe 宽高比 + 构图抽帧 |
| 3 | 第一帧完整显示封面标题 | 抽 frame 0，OCR + 非黑检测 |
| 4 | 封面 ≤ 2 行、每行 ≤ 4 字 | 分镜校验 |
| 5 | 第二镜头起移除封面标题 | 抽第二镜头帧 OCR |
| 6 | 横屏动态导航与章节同步 | 抽帧检测 + 时间戳比对 |
| 7 | 全片统一高级配色 | 主色占比统计 |
| 8 | 中英字幕逐句同步 | subtitle.json vs 语音 |
| 9 | 字幕与可视化无溢出遮挡 | 宽度实测 + 安全区 |
| 10 | 每 3 秒完成视觉节奏评估 | storyboard 记录完整性 |
| 11 | 每秒存在合理动态或阅读安排 | animation_plan 覆盖率 |
| 12 | 核心知识点有效可视化 | 组件覆盖关键论据 |
| 13 | 声音清晰、音效适度 | 响度 + 音效密度 |
| 14 | 内容无失真、素材合规 | 文稿比对 + CREDITS |
| 15 | 成片完整解码可播放 | `ffmpeg -v error -i x -f null -` |

## 3. 自动检测怎么做

```bash
# 完整解码检测（无错误即通过）
ffmpeg -v error -i output.mp4 -f null - 2> decode.log

# 首帧黑屏检测
ffmpeg -i output.mp4 -vf "blackdetect=d=0.05:pix_th=0.10" -an -f null - 2>&1 | grep black

# 抽关键帧做视觉复核
ffmpeg -ss 0 -i output.mp4 -frames:v 1 f_cover.png
ffmpeg -ss 2.5 -i output.mp4 -frames:v 1 f_scene2.png
ffmpeg -ss <chapter_t> -i output.mp4 -frames:v 1 f_chapter.png

# 响度检测
ffmpeg -i output.mp4 -af ebur128 -f null - 2>&1 | tail -20
```

## 4. 自动修复策略

| 扣分项 | 修复动作 | 需要重跑 |
|---|---|---|
| 封面超字数 | 重写标题 → 重渲染封面段 | 封面段 |
| 封面非首帧 | 调整 cover.duration=0，元素静态起始 | 封面段 |
| 第二镜头标题残留 | 检查 scene.cover_visible=false 与元素销毁 | 第二镜头 |
| 导航缺失/超 8% | 补 navigation 配置、调高度 | 导航层 |
| 字幕溢出 | 断句 → 优化英文 → 降字号 ≤10% | 字幕层 |
| 字幕不同步 | 用 timemap 重算时间戳 | 字幕层 |
| 构图长时间不变 | 在 6–9s 处插知识镜头 | 该段落 |
| 动效缺失 | 给空白秒补 a5 或 a2 | 该段落 |
| 响度不达标 | 重跑 loudnorm | 音频层 |
| 音效过多 | 按密度规则裁到 1–3/10s | 音频层 |
| 解码失败 | 查编码参数、重封装 | 全片 |

修复粒度：**能局部重渲就局部重渲。** 不要为一个字幕问题重跑整条视频。

## 6. 不许做的事

- ❌ 只靠模型自评"我觉得不错"就宣布合格
- ❌ 跳过解码检测
- ❌ 不抽帧就直接交付
- ❌ 把低于 90 分的成片说成"基本合格"
- ❌ 修复后不重跑对应检测

## 7. 人工复核建议点

模型容易漏的三处：

1. **知识准确性** —— 逻辑是否成立，数据是否被误用。
2. **节奏是否"赶"** —— 观众有没有时间读。
3. **是否"像 PPT"** —— 连续卡片镜头是否过多。
